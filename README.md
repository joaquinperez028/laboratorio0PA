                                      Gestor de Publicaciones Académicas

Desarrollamos el programa para que cumpliera con los requerimientos del lab, permitiendo cargar las publicaciónes que aparecen
en la letra asi como los investigadores, lograr las relaciones pedidas, listar las publicaciones tanto a nivel general como
filtradas por fecha y palabra clave, también la aplicación permite la eliminacion de publicaciónes.

A continuación explicamos lo que logra cada parte del menú:

  1. CARGAR PUBLICACIÓNES ---> Cumple con los pasos (a), (b) y (c) de la letra cargando las publicaciones requeridas.
  2. CARGAR INVESTIGADORES ---> Cumple con el paso (e) crear investigadores.
  3. IMPRIMIR TODAS LAS PUBLICACIÓNES ---> Pasos (d) y (k): imprime por consola las Publicaciónes creadas utilizando el 
                                           método getDT().
  4. IMPRIMIR TODOS LOS INVESTIGADORES ---> Paso (f): Imprime los investigadores cargados usando el método toString().
  5. REGISTRAR RELACIÓNES INVESTIGADORES / PUBLICACIÓNES ---> realiza las relaciónes entre Publicaciónes e Investigadores
                                                              pedidas en la parte (g).
  6. MOSTRAR UNA PUBLICACIÓN ---> Lista Publicaciónes filtradas por fecha y palabra clave utilizando la operación 
                                  listarPublicaciones() solicitada en los pasos (h) y (j).
  7. ELIMINAR UNA PUBLICACIÓN ---> Eliminar un objeto de la clase Publicación parte (i).
